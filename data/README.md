# Data setup

The competition dataset is not redistributed in this repository.

Download the files from the [Kaggle competition data page](https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data) and place the following files in this directory:

```text
data/
├── train.csv
├── test.csv
├── sample_submission.csv
└── data_description.txt
```

The notebook searches this directory automatically. Kaggle may require you to sign in and accept the competition rules before downloading the files.
